# 作战档案

一局一份，按开打顺序编号。文件名格式：`编号-类型-地图.md`。

每份要能回答三件事：这局怎么打的、输赢卡在哪、下次改什么。

| [003](003-战役第一关-DividingRiver.md) | 2026-10-28 | Dividing_River（战役 l010，Medium） | **胜** | 首关 10 分 30 秒通关：2 座抽取器 → Ctrl+点击爆 55 台坦克 → 右键全军压上，拆光敌方工厂与制造仪 |

## 写法

1. **数据只写读到的**：`/state`、`/units`、截图，数字照原样。
2. **时间线写动作**：谁点了什么、API 下了什么令，别写"应该"。
3. **输赢卡点单独一节**，能复述成一条可检验的假设。
4. **下次怎么改**写具体到建造顺序和单位比例。
