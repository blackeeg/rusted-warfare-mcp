# 002 沙盒 · 建造流程推导

- 日期：2026-10-28
- 地图：Crossing Large (10p) 无人沙盒（`isHost: true`，`others: 0`）
- 起始家底：指挥中心 1（4000 血）、建造者 1（170 血）、资金 4135、收入 18/s
- 目的：把「怎么建造」一步一步推出来，每一步都用 `/units` 或截图验证真的发生了

## 1. 玩家给的流程（原话）

> 选择一个或多个建造者，在侧边栏按下建筑，显示投影后放在你想要的地方。然后资源抽取器这一类要放在资源坑上。

推导下来成立的版本：

1. **选中建造者**（点地上的建造者，或 API `select`）。侧栏变成建造列表。
2. **点侧栏里的建筑**。进入落位模式，屏幕上出现跟随鼠标的半透明投影。
3. **在目标位置点一下**。合法则落地，非法则无事发生。
4. **建造者自己走过去施工**，完工后单位出现在 `/units`。

抽取器这一类**必须点在资源坑上**，普通空地放不下。

## 3. 几条关键性质

- **建造是走位 + 施工，不是瞬间出现**。点完落位，先看建造者移动，再看单位出现。判定建造令生效最省事的办法：看建造者的坐标有没有变。
- **升级 T2 是队列活**，不是瞬时开关。点完侧栏那格会显示 `(1)`，约 25 秒后才真正换成 T2 单位列表。看到 `(1)` 就说明点中了。
- **收入账**：每座资源抽取器 **+8/s**。18 → 34（开局 2 座）→ 42（第 3 座）。
- **同一格连点会排队**：点 3 次 = 队列 3 台，不是重复触发。
- **一座建筑只有一个生产队列**。Ctrl+点击只是把 10 台塞进同一条队列，吞吐不变；要真提速得**多造几座陆军工厂**，每座各吃一条队列（老师指出）。
- **面板行位置会随内容变化**。建造者面板（14 项）和 T2 工厂面板（13 项）的格子 y 不同，同一套坐标不能跨面板复用。
- **落位点在窗口内任意位置**，建造者会自己走过去；超出建造范围也不会报错，只是要多走一段。

## 5. 怎么校准一格坐标（不用猜）

1. 把鼠标放到候选位置，**截图看哪一格高亮**（hover 是蓝色底）。
2. 或者点一下，**截图看队列数字**（`坦克 (1)`、`升级 - T2 (1)`），数字出现就说明点中。
3. 两个方法都只依赖截图和 `/state`，不需要读游戏内存。

本轮的教训：我先按 1.25 倍换算去猜，结果 426 那格其实是「防空导弹坦克」，重型坦克在它下面一行 (477)。靠截图里的队列数字才发现。

## 7. 画面坐标换算（重要）

侧栏格子的画面坐标**不是**简单的 app×1.25，纵向另有偏移。实测两点定出来的式子：

```
画面 y ≈ 0.925 × app_y + 92        →  app_y ≈ (画面 y − 92) / 0.925
画面 x ≈ 1.25 × app_x
```

用它反推格子：先量出格子中心的画面 y，再换算成 app 坐标去点。行心画面 y 依次 336 / 385 / 434 / 483 / 533 / 580。

反例：悬浮坦克格子中心画面 y≈434 → app 370；重型坦克 533 → app 477。这两个都实测点中过。

## 8. 批量下单（Ctrl+点击）

- **普通点击 = 1 个。**
- **Ctrl+点击 = 一次排一批。** 实测在「悬浮坦克」上 Ctrl+点击两次，队列显示 `悬浮坦克 (19)`——按这个看单次约 10 个，不是 5 个。
- **队列满了之后，别的格子点不动。** 这轮先排了 10 台重型坦克，回头点「侦察者」毫无反应，一开始误判成坐标错了。判据：目标格子后面没有出现 `(n)`。
- 点击间隔压到约 0.4 秒一次（原脚本 0.85 秒），仍然稳定。脚本：`tools/click_seq.ps1`，坐标用 `x,y`，右键加 `r`，Ctrl 加 `c`，例：`-Clicks "1484,477,c;1380,370"`。
