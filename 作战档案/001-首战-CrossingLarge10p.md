## 2. 时间线（动作 + 读数）

1. **确认点击能打中面板**：选中陆军工厂后点「坦克」格，`坦克 5 → 6`，`own.count 18 → 19`。这是第一次证明合成点击真的生效。
2. **批量下单**：连点「坦克」5 次 → 6 秒后 `坦克 9`；再 10 次 → 25；再 8 次 → 28。产能上限约 **1 辆 / 35 秒**（收入 26/s，坦克单价约 900）。
3. **第一次推进**：`select 坦克` → `move 700,1350`。命令报「28/28 成功」。
4. **坐标踩坑**：8 秒后坦克群出现在世界坐标 y≈350，不是 1350。判定 `move` 的 y 轴与 `/units` 的 y 轴反向（近似 `y_api = 1700 - y_world`）。这次"失误"恰好把 28 辆坦克扔到敌方北岸基地脸上。
5. **战果**：敌方 `陆军工厂@630,230` HP 1200 → **0**，`空军基地@850,210` HP → **0**。敌方单位总数 144 → 109。
6. **第二次推进**：`select 坦克` → `move 1770,1490`（打东北角的第二座工厂）。此后未再确认战果。
7. **崩盘**：我方单位数从 45 掉到 37、总血 13107 → 11427 → 5475 → 0。陆军工厂血量 1200 → 1135 → 消失。
8. **误判**：工厂已死，但 `/act?do=select&v=陆军工厂` 仍能"选中 1 个"。之后所有针对面板的点击（升级 T2、坦克）全部无效——因为面板属于一个已经死掉的单位。**这是本局最大的判断失误。**
9. **终局**：`over: true`，我方存活 0，敌方 99 单位 / 63775 血，我方结余资金 75141 无处可花，收入归 0。

## 4. 输在哪

**单一兵种 + 离补给线太远。** 28 辆坦克没有任何防空掩护，一路推到距基地约 1300 格的敌方北岸；敌方用空中单位和远程火力逐层剥掉坦克，坦克对空为零，只能挨打。修复湾在第 7 步前就已经没了，伤兵无法回血。

**工厂死得太早。** 家底只有 1 座陆军工厂，它一没，75141 的资金全部变成废纸。

## 5. 下次怎么改

1. 先补经济：**2~3 个资源抽取器**，把收入从 26/s 拉到 60~80/s。
2. **第二座陆军工厂**（建造者造），产能翻倍，别把鸡蛋放一个厂。
3. 再升 T2 → 重型坦克（HP 600，是坦克 210 的 2.9 倍）。
4. 出兵必混编防空（侦察者 / 防空炮），只在自己防空伞下推进。
5. 一次最多投一半兵力，留预备队在基地。

## 6. 本局学到的操作事实

| 事实 | 证据 |
| --- | --- |
| 合成点击能打中游戏面板 | 点「坦克」后 `坦克 5 → 6`，`own 18 → 19` |
| 键盘热键打不进（除轮询类） | 按 `U` 升 T2 无效；方向键能滚镜头（轮询） |
| 游戏失焦或 ESC 菜单打开时画面冻结 | 同一帧 md5 重复；`/units` 位置两次采样不变 |
| 冻结时点「继续」可恢复 | 点击后 2 秒采样，单位位置开始变化 |
| `move` 的 y 轴与世界 y 相反 | 下 `y=1350`，坦克群落在 `y≈350` |
| 已死单位仍能被 API "选中" | 工厂 HP 0 后 `select` 仍返回「选中 1 个」 |
